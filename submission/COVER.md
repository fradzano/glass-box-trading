# Cover image brief — SUB-06

Target file: `submission/cover.png` (rendered later from this brief; not
produced by this document). Format: PNG or JPG, exact 16:9 aspect ratio.

## Requirements

- **Legible at thumbnail size.** The event listing will scale this down
  aggressively; text must survive shrinking to roughly card-sized display.
  Favor one short headline and minimal supporting text over dense copy.
- **Project name.** "Glass Box Trading" appears clearly, once, as the
  dominant text element.
- **The one-line control model.** "AI proposes; deterministic gates
  dispose." appears as a subordinate line — legible but not competing with
  the project name for attention.
- **No performance claim.** No P&L number, percentage, "profitable",
  "winning", or any other outcome claim on the image. The cover sells the
  architecture idea, not a result — the result lives in the dashboard,
  one-pager, and video, each with its own cutoff label.
- No fabricated screenshots or UI mockups presented as if they were the real
  dashboard; if a dashboard excerpt is used, it must be an actual rendered
  screenshot from the pinned presentation-cutoff route, not a redraw.

## Visual direction

- 16:9 canvas, dark or neutral background consistent with the dashboard's own
  visual language (glass/audit motif — panels, ledger lines, a visible
  boundary between "proposal" and "decision" — rather than generic trading
  imagery like candlestick charts or bull/bear icons).
- Two-part composition suits the control-model line well: a left/right or
  top/bottom split visually separating "AI proposes" from "gates dispose,"
  echoing the architecture's own separation of concerns.
- Avoid stock-photo trading-floor or rocket-ship imagery; this project's
  claim is about auditability and restraint, not hype.
